# PWFB Financial Portal

Standalone financial operations portal for Perfect Wisdom For Better Ltd. (PWFB).

## Features

- Monthly payroll
- DM 1 / DM 2 filtering
- Salary and bank disbursement schedule
- Cooperative savings and loan ledger
- Search
- Payroll summary cards
- Responsive mobile layout
- Nigerian Naira formatting
- CSV/export-ready interface

This project is completely separate from `PWFB/pwfb-microfinance`.
